# Supermarket Sales Analysis using Python

## Overview
This project focuses on analyzing supermarket sales data using Python. The analysis includes data cleaning, exploratory data analysis (EDA), statistical insights, and visualizations to understand customer behavior, product performance, and sales trends.

The project was developed as part of a data analytics assignment and demonstrates practical data analysis workflows using Python libraries.

---

## Dataset
The dataset contains daily supermarket sales records including:

- Product lines
- Branch locations
- Customer types
- Gender
- Sales transactions
- Payment information

---

## Objectives

- Perform data loading and inspection
- Clean and preprocess the dataset
- Analyze sales trends and customer behavior
- Generate visual insights using charts and plots
- Identify business recommendations from the data

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis Performed

### Data Cleaning
- Checked missing values
- Converted date columns into datetime format

- Top-performing product lines
- Branch-wise average sales
- Customer spending behavior
- Gender-based purchasing analysis

### Data Visualization
- Bar charts
- Histograms
- Box plots
- Pair plots
- Correlation heatmaps
